# Whitespace design source

Unpacked from the Claude Design export "Whitespace — web app" (2026-11-08). Each file is one artboard's
`.dc.html` source (markup in `<x-dc>`, inline styles, `{{holes}}` for data). Read them for exact tokens,
spacing, copy and structure; do not ship them.

- `Epics.dc.html`: Research epics (the home/workspace screen: epics, threads, suggested threads, activity)
- `Explore.dc.html`: search / "from my paper", research areas, filters, map, concept panel
- `Gaps.dc.html`: gaps and open problems on one screen, with the gap drawer

Tokens: bg #F6F6F3, surface #FFFFFF, border #E6E6E1, ink #15171C, muted #5B606B, accent #2952E3;
IBM Plex Sans / Mono; 56px header.
